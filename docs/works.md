## Zect

2023年8月「HELLO, VOCALOID vol.1」で VJ としてデビュー。以来、ボカロをはじめとする合成音声楽曲を起点としたクラブイベントを中心に活動し、優しい音から激しい音まで、幅広いサウンドの VJ を経験。

東京を中心に北海道や大阪でも、小さなクラブハウスからライブハウス、WOMB や clubasia などの大きな会場まで、規模も地域も問わずさまざまな箱で VJ を担当。短い映像クリップを音に応じてシェーダーで加工・展開していくスタイルを軸に、コンセプトのあるイベントでは、その日限りの VJ システムを組み上げることもある。

クラブ VJ のほかにも、ファンメイドの 2D ライブやアイドルのワンマンライブで映像オペレーター・VJ を務めるなど、活動の場は幅広い。

2024年には、クラブイベント「Try Force」を主催として立ち上げた。「出演できる現場が少ない」「DJ としてもっと多くの人とつながりたい」という声に応えるイベントとして、1年あまりほぼ毎月開催。ここで初めてクラブに立った DJ や、この場で見出された新人たちが、いまでは大きな箱に呼ばれ、名前を知られる存在になっている。

現在は、7つのクラブイベントと2つのライブイベントにレギュラー VJ として参加している。

Zect は、2023年8月の「HELLO, VOCALOID vol.1」で VJ としてデビュー。以来、ボカロ（VOCALOID）を起点としたクラブイベントを中心に活動し、優しい音から激しい音まで、幅広いサウンドに映像を合わせてきた。

小さなクラブハウスからライブハウス、WOMB や clubasia のメインステージまで、規模を問わずさまざまな箱で VJ を担当。イベントのコンセプトに合わせて、その日限りの VJ システムを組み上げることを得意とする。

クラブ VJ のほかにも、ファンメイドの 2D ライブで映像オペレーター・VJ を務めるなど、活動の場は幅広い。<!-- TODO: 「hoge など」の具体例を入れる → 例：〇〇や〇〇など、VJ 以外の映像制作にも対応する。 -->

2024年には、クラブイベント「Try Force」を立ち上げ、主催した。「出演できる現場が少ない」「DJ としてもっと多くの人とつながりたい」という声に応えるイベントとして、1年あまりほぼ毎月開催。ここで初めてクラブに立った DJ や、この場で見出された新人たちが、いまでは大きな箱に呼ばれ、名前を知られる存在になっている。

現在は、7つのクラブイベントと2つのライブイベントにレギュラー VJ として参加している。
